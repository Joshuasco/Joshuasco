## 👤 About me

I am a **Full-Stack Software Engineer** with 5+ years of experience building resilient, scalable web applications and enterprise systems. Drawing from a foundational background in Computer Engineering and Embedded Systems, I design high-level software with a deep appreciation for low-level mechanics—from memory allocation and CPU overhead to system-wide architectural performance.

My work spans high-throughput platforms across SaaS, multi-tenant architectures, FinTech systems, ERP applications, e-commerce, and enterprise management tools.

* **Low-Level Edge:** Bringing hardware-level awareness (memory optimization, CPU efficiency, concurrency) to high-level backend architecture.
* **Complex Logic & Reliability:** Designing fine-grained Role-Based Access Control (RBAC), request idempotency, race condition mitigation, and multi-tenant data isolation.
* **CS Fundamentals:** Leveraging strong data structures, algorithms, and critical thinking to solve bottleneck issues under aggressive deadlines.
* **Versatile Execution:** Thriving both independently in isolation and as a collaborative team player committed to delivering production-ready code.
